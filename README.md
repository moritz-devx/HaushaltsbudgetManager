Ein Dashboard für ein Haushaltsbudget
 
Features:
⦁	Der User kann ein monatliches Haushaltsbudget (in Euro) eintragen
⦁	Das Verbleibende Budget für diesen Monat wird immer auf der Seite angezeigt
⦁	Man kann Einnahmen und Ausgaben hinzufügen
⦁	Betrag
⦁	Art (Einnahme oder Ausgabe)
⦁	Intervall (Einmalig, Wöchentlich, Monatlich)
⦁	Alle Einnahmen und Ausgaben werden in einem GridControl aufgelistet und können bearbeitet oder gelöscht werden
⦁	Wenn eine neue Einnahme oder Ausgabe eingetragen, aktualisiert oder gelöscht wird, aktualisiert sich auch die Anzeige vom verbleibenden Budget
⦁	Wenn man eine  Ausgabe einträgt die das Budget ins Minus bringt, wird ein Popup mit einer Warnung angezeigt, aber man kann trotzdem ins Minus gehen
⦁	Zum speichern wird der LocalStorage des Browsers verwendet
