Ein Dashboard für ein Haushaltsbudget <br/> <br/>
 
Features: <br/>
⦁	Der User kann ein monatliches Haushaltsbudget (in Euro) eintragen <br/>
⦁	Das Verbleibende Budget für diesen Monat wird immer auf der Seite angezeigt <br/>
⦁	Man kann Einnahmen und Ausgaben hinzufügen <br/>
⦁	Betrag <br/>
⦁	Art (Einnahme oder Ausgabe) <br/>
⦁	Intervall (Einmalig, Wöchentlich, Monatlich) <br/>
⦁	Alle Einnahmen und Ausgaben werden in einem GridControl aufgelistet und können bearbeitet oder gelöscht werden <br/>
⦁	Wenn eine neue Einnahme oder Ausgabe eingetragen, aktualisiert oder gelöscht wird, aktualisiert sich auch die Anzeige vom verbleibenden Budget <br/>
⦁	Wenn man eine  Ausgabe einträgt die das Budget ins Minus bringt, wird ein Popup mit einer Warnung angezeigt, aber man kann trotzdem ins Minus gehen <br/>
⦁	Zum speichern wird der LocalStorage des Browsers verwendet <br/>
